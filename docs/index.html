    Conexión con GitHub

    Para guardar cambios desde este dispositivo hace falta un token de GitHub. Se guarda solo aquí, en este navegador o app.

    ¿Cómo crear el token?
    1. En github.com, toca tu foto de perfil y entra a Settings.
    2. Baja hasta Developer settings, luego Personal access tokens y Fine-grained tokens.
    3. Pulsa Generate new token y ponle un nombre, por ejemplo "app publicador".
    4. En Repository access elige Only select repositories y marca solo tu repositorio del publicador.
    5. En Repository permissions pon Contents: Read and write y Actions: Read and write.
    6. Pulsa Generate token, copia el texto que aparece (solo se muestra una vez) y pégalo arriba.

    Quien tenga este token puede cambiar los archivos de ese repositorio. Si pierdes el teléfono, bórralo desde la misma pantalla de GitHub.

    Si la dejas vacía, se usa la descripción general.
